# KeyCraft
Shortcuts for Windows, Linux and macOS. Open index.html in any browser, or build the apps below.

## Option A: build the .exe on your own PC (needs Node.js)
npm install
npm start            (test the app)
npm run build:win    (the installer appears in the dist folder)

## Option B: let GitHub build it (no setup)
Push this folder to a GitHub repository. Open Actions -> Build apps -> download the Windows, Linux or macOS file.

## Phone
Put the folder on any web host (GitHub Pages is free), open the link on your phone, then choose "Add to Home Screen".
"# computer-shortcuts"
